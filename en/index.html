The problem

One attack, four innocent-looking steps

Each step looks normal on its own: reading a file, querying the database, sending a web request. Only together do they reveal an attack. ShieldTrail looks at them together.

01prompt injection

Hidden instruction

The agent opens an invoice PDF that contains text written for the AI, not for humans.

02out-of-scope tool

Unusual query

It runs a query the task never needed: all customers with their card numbers.

03unknown domain

Sending the data

It tries to send that list to a website nobody has ever used.

04blocked

ShieldTrail blocks it

The request never leaves the app. The whole chain is saved with the reason.

How it works

Three ideas, nothing more

It follows the whole task

What the agent reads, the tools it calls and the requests it sends are linked together. Once a hidden instruction gets in, every later step is watched closely.

It stops only the bad step

The request that would send data out never leaves. The rest of the app keeps working, and every decision says why.

Watch first, block later

Start in watch-only mode: ShieldTrail records what it would block, without touching anything. Turn on blocking, rule by rule, when you trust it.

In your code

A few lines in your app

One guard, then wrap what the agent reads, the tools it calls and the work it does.

Full guide 
// lib/guard.ts — the rules live in shieldtrail.policy.json
import { createGuard } from 'shieldtrail/node';

export const guard = createGuard({
  secrets: [{ name: 'STRIPE_KEY', value: process.env.STRIPE_KEY, domains: ['api.stripe.com'] }],
});

// where your agent runs
const trace = guard.startTrace({ agent: 'support-bot', task: 'Answer ticket #4521', allowedTools: ['tickets.*'] });
await trace.context({ source: attachmentUrl, text: pdfText });   // what the agent reads
const rows = await trace.tool('db.query', args, () => db.query(args));
await trace.run(() => agent.next());   // every fetch inside goes through the rules
// a request to an unknown domain after an injection throws GuardBlockedError: it never leaves

console.log((await trace.chain()).narrative);
